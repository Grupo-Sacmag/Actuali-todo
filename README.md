# Actuali-todo

Proyecto para la actualización de tarifas e índices de depreciaciones de los sistemas.

## Estructura de la Solución
- **Actuali_Todo**: Proyecto principal en C# (Windows Forms).
- **ACTUALI TODO**: Proyecto de instalación (Setup / Installer).

## Ramas (Gitflow)
- `main`: Código estable de producción.
- `Dev`: Rama de integración de desarrollo.
- `pochoclo`: Rama de trabajo actual (Feature branch).

## Uso
1. Clona el repositorio.
2. Abre el archivo `Actuali_Todo.sln` usando Visual Studio.
3. Asegúrate de tener los componentes necesarios instalados para C# y Visual Studio Installer Projects.
